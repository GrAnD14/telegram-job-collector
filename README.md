# Telegram Job Collector

Расширение для Google Chrome / Chromium-браузеров, которое ищет вакансии в публичных Telegram-каналах и публичных Telegram-группах, фильтрует неподходящие публикации и может отправлять найденные вакансии в личный Telegram-бот.

Текущая версия: **2.9.2**

> Проект не использует Telegram User API, `api_id`, `api_hash` или авторизацию через пользовательский Telegram-аккаунт.

---

## Изменения 2.9.2

- Добавлен независимый от баллов отсев упоминаний трейдинга: `трейдинг`, `трединг`, `трейдер`, `trading`, `traiding`, `trader` и русские словоформы. Регистр, Markdown и невидимые разделители не мешают проверке. Это личное исключение сферы, а не утверждение о мошенничестве каждого работодателя.
- Добавлен отсев сочетания: зарплата от **90 000 ₽** (нижняя граница диапазона), до **3 коротких обязанностей / 70 слов**, минимум два признака простой работы (готовые ответы, чат, передача вопросов, запись результатов, ввод данных), отсутствие опыта и хотя бы один дополнительный признак: компания не указана, короткие смены/совмещение или быстрый приём без резюме.
- Порог 90 000 ₽ — настройка эвристики `SIMPLE_JOB_HIGH_SALARY_RUB`, а не оценка рынка. Одна высокая зарплата или короткий текст сами по себе не приводят к отклонению. Явная годовая оплата и USD/EUR этой рублёвой эвристикой не оцениваются; суммы без валюты трактуются как рубли.
- Причины видны в аудите и JSON: `excluded_trading` и `suspicious_simple_job`. Подозрительные простые вакансии остаются доступными для ручной проверки и не отправляются автоматически, даже при минимальном пороге баллов.
- Эвристика не доказывает мошенничество и не гарантирует обнаружение всех подозрительных объявлений.

Проверка фильтров без браузера и отправки сообщений (Node.js 18+):

```sh
node --test tests/filters.test.cjs
```

Для обновления распакуйте `telegram-job-collector-v2.9.2.zip` в папку установленного расширения и нажмите **Обновить** на его карточке в `chrome://extensions`. Существующий экземпляр расширения удалять не нужно.

## Что это за программа

Telegram Job Collector — браузерное расширение для автоматизации поиска вакансий в публичных источниках Telegram.

Расширение:

- читает публикации из публичных Telegram-каналов;
- умеет работать с некоторыми публичными Telegram-группами;
- анализирует текст публикаций;
- пытается отличать вакансии от:
  - рекламы услуг;
  - самопрезентаций специалистов;
  - резюме соискателей;
  - рекламных подборок;
  - партнёрских / сетевых схем;
  - явно офисных вакансий;
- определяет формат работы;
- ищет зарплату;
- пытается определить требуемый опыт;
- извлекает контакты;
- присваивает вакансии баллы;
- отдельно сохраняет вакансии, у которых формат работы не удалось определить;
- умеет проводить аудит без отправки сообщений;
- может отправлять прошедшие фильтр вакансии в Telegram через собственного BotFather-бота;
- хранит историю уже отправленных вакансий, чтобы не отправлять одно и то же повторно.

Основная задача программы — сократить количество ручного просмотра Telegram-каналов при поиске удалённой работы.

# Основные возможности

## Публичные Telegram-каналы

Обычные публичные Telegram-каналы читаются через публичную веб-ленту Telegram:

```text
https://t.me/s/channel_name
```

Например:

```text
https://t.me/frilancekomfort
```

или:

```text
@frilancekomfort
```

---

## Публичные Telegram-группы

Расширение также поддерживает публичные Telegram-группы.

Для них обычная `/s/`-лента Telegram отсутствует, поэтому используется другой механизм — публичные Telegram Post Widget страницы отдельных сообщений.

Например:

```text
https://t.me/vakansii_infobiz
```

или:

```text
@vakansii_infobiz
```

Для некоторых групп поиск актуального ID сообщения может занимать больше времени, поскольку ID сообщений Telegram могут идти с большими пропусками.

Если автоматический поиск работает слишком долго, можно указать ссылку непосредственно на одно из свежих публичных сообщений группы:

```text
https://t.me/group_name/123456
```

Это позволяет расширению сразу получить актуальную точку для сканирования.

# Что программа считает подходящей вакансией

Расширение анализирует публикацию по нескольким признакам.

Например:

- наличие отдельной вакансии;
- название должности;
- наличие обязанностей;
- условия работы;
- удалённый формат;
- зарплата;
- опыт;
- возможность работы без опыта;
- контакты для отклика;
- признаки найма сотрудника.

Если включена настройка:

```text
Только удалённые вакансии
```

то явно офисные вакансии автоматически отбрасываются.

---

# Статусы вакансий

Публикации делятся на несколько основных категорий.

### Подходит

Вакансия прошла основные фильтры и может быть отправлена в Telegram-бот.

Пример:

```text
Менеджер поддержки
Удалённо
Без опыта
от 60 000 ₽
```

---

### Формат ?

Публикация похожа на полноценную вакансию, но из текста невозможно уверенно определить формат работы.

Например:

```text
Ищем ассистента.

Обязанности:
...

Оплата:
50 000 ₽
```

Но в тексте нигде не указано:

```text
удалённо
офис
гибрид
```

Такие вакансии **не отправляются автоматически**, если включён фильтр только удалённой работы.

Они сохраняются в аудите для ручной проверки.

---

### Отклонено

Публикация не прошла фильтры.

Причинами могут быть:

```text
офисная работа
гибрид без подтверждённой удалёнки
реклама услуг
самопрезентация
резюме соискателя
реклама Telegram-канала
партнёрская / сетевая схема
слишком мало признаков вакансии
нет текста
```

---

# Фильтрация самопрезентаций

В публичных чатах вместе с вакансиями часто публикуют объявления специалисты, которые сами ищут клиентов.

Например:

```text
#помогу

Я SMM-специалист.
Веду проекты под ключ.
Беру 2 проекта на сентябрь.
Пишите мне в личку.
```

Такие объявления не являются вакансиями работодателя и должны отбрасываться.

Расширение умеет распознавать многие подобные конструкции.

Также фильтруются объявления вида:

```text
Ищу работу
Ищу позицию
Ищу проект
Ищу клиентов
Беру проекты
Оказываю услуги
Могу помочь вашему бизнесу
```

При этом само слово:

```text
#ищу
```

не считается достаточной причиной для отклонения, поскольку работодатели тоже часто пишут:

```text
#ищу #менеджер
```

---

# Антискам-фильтрация

Расширение пытается отбрасывать некоторые опасные или нетипичные предложения.

Например:

- партнёрские схемы вместо обычной вакансии;
- сетевой маркетинг;
- доход от товарооборота;
- построение команды партнёров;
- некоторые подозрительные схемы заработка;
- неоплачиваемую работу.

Однако:

> Telegram Job Collector не является системой проверки работодателей и не может гарантировать безопасность вакансии.

Даже если вакансия прошла фильтр, перед откликом рекомендуется самостоятельно проверять:

- название компании;
- сайт;
- юридическое лицо;
- отзывы;
- контакты;
- условия трудоустройства.

Никогда не передавайте работодателю:

- пароль;
- SMS-код;
- код Telegram;
- данные для входа в Госуслуги;
- полный доступ к банковскому аккаунту.

Не переводите деньги за:

- трудоустройство;
- оформление;
- обучение перед трудоустройством;
- доступ к вакансии;
- получение зарплаты.

# Аудит

У расширения есть специальный режим:

```text
Аудит без отправки
```

Он позволяет проверить работу фильтра без отправки вакансий в Telegram.

После аудита можно скачать JSON-файл.

В нём содержится информация о каждой проверенной публикации:

```json
{
  "link": "...",
  "channel": "...",
  "date": "...",
  "title": "...",
  "company": "...",
  "workFormat": "...",
  "salary": "...",
  "experience": "...",
  "contacts": [],
  "score": 0,
  "filterStatus": "...",
  "rejectReason": "...",
  "warnings": [],
  "text": "..."
}
```

Также сохраняется статистика по источникам.

Например:

```json
{
  "checked": 95,
  "accepted": 34,
  "uncertain": 20,
  "rejected": 41
}
```

# Статус источников

Для каждого источника показывается отдельный статус.

Например:

```text
@frilancekomfort
Тип: channel
Статус: ok
Проверено: 35
```

или:

```text
@vakansii_infobiz
Тип: public_group
Статус: ok
Проверено: 95
Последний ID: 332763
```

Для публичных групп дополнительно могут отображаться:

```text
latestId
latestDate
discoveryMethod
discoveryProbes
discoveryBands
scannedIds
```

Это позволяет понять, действительно ли источник был прочитан.

# Telegram Bot

Для автоматической отправки вакансий используется обычный Telegram-бот, созданный через BotFather.

Telegram Job Collector не требует авторизации в пользовательском аккаунте Telegram.

Не нужны:

```text
api_id
api_hash
номер телефона Telegram
Telegram User API
```

Нужен только:

```text
Bot Token
Chat ID
```

---

# Создание Telegram-бота

Откройте Telegram и найдите:

```text
@BotFather
```

Создайте нового бота командой:

```text
/newbot
```

BotFather выдаст токен примерно такого вида:

```text
1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Не публикуйте этот токен.

Не добавляйте его в GitHub.

---

# Получение Chat ID

После создания бота:

1. Откройте своего бота.
2. Нажмите `Start` или отправьте ему любое сообщение.
3. Откройте расширение.
4. Вставьте Bot Token.
5. Нажмите кнопку поиска Chat ID.
6. Расширение попробует определить ваш Telegram Chat ID автоматически.

После этого можно выполнить тестовую отправку.

В поле источников указывается один Telegram-источник на строку.

Например:

```text
@frilancekomfort
@vakansii_infobiz
@edmarketclubjob
```

Также можно использовать:

```text
https://t.me/frilancekomfort
https://t.me/vakansii_infobiz
```

Для публичной группы можно указать конкретное сообщение:

```text
https://t.me/edmarketclubjob/531944
```

Это особенно полезно, если автоматический поиск актуального сообщения занимает слишком много времени.

# Настройки поиска

## Период поиска

Можно указать количество дней.

Например:

```text
7
```

Расширение будет искать публикации примерно за последние 7 дней.

---

## Минимальный балл

Используется система баллов.

Например:

```text
45
```

Чем выше значение, тем строже фильтр.

---

## Только удалённая работа

Если включено:

```text
requireRemote = true
```

расширение будет отправлять только вакансии, в которых удалось подтвердить удалённый формат.

Если формат не определён, вакансия попадёт в раздел:

```text
Формат ?
```

---

## Только новые вакансии

При включённой настройке:

```text
sendOnlyNew = true
```

расширение хранит историю отправленных публикаций и старается не отправлять одну вакансию повторно.

После этого использовать:

# Важно при обновлении расширения

Настройки расширения хранятся в:

```text
chrome.storage.local
```

Там могут находиться:

- Bot Token;
- Chat ID;
- список источников;
- настройки;
- история уже отправленных вакансий;
- данные последних найденных ID публичных групп.

Если удалить расширение и установить его заново как другое расширение, локальные данные могут быть потеряны.

Поэтому при обновлении рекомендуется:

1. Не удалять старое расширение.
2. Заменить файлы в той же папке.
3. Открыть:

```text
chrome://extensions/
```

4. Нажать:

```text
Reload / Обновить
```

Так вероятность сохранения настроек выше.

# Как работают публичные группы

У Telegram нет такой же удобной публичной `/s/`-ленты для групп, как для каналов.

Поэтому расширение ищет доступные публичные сообщения по их ID через Telegram Post Widget.

Из-за этого:

- группы могут сканироваться медленнее каналов;
- между ID могут быть большие промежутки;
- некоторые сообщения могут быть недоступны через публичный веб-интерфейс;
- иногда полезно вручную указать ссылку на свежее сообщение.

В версии 2.9 добавлен механизм поиска разреженных ID.

Пустой ID больше не считается автоматически концом истории группы.

---

# Производительность

Обычные публичные каналы обычно проверяются значительно быстрее публичных групп.

Для крупной публичной группы расширению иногда приходится проверять сотни ID, чтобы получить несколько десятков реальных сообщений.

Поэтому сканирование группы может занимать заметное время.

Во время сканирования рекомендуется не закрывать popup расширения.

# Ограничения

Telegram Job Collector использует эвристические правила, а не полноценную семантическую AI-модель.

Из-за этого возможны:

### False Positive

Плохое или сомнительное объявление может быть принято как вакансия.

Например объявление может формально содержать:

```text
удалённо
зарплата
обязанности
без опыта
```

но при этом фактически быть сомнительной схемой.

---

### False Negative

Настоящая вакансия может быть отклонена.

Особенно если она написана очень коротко или нестандартно.

---

### Неопределённый формат

Вакансия может быть настоящей, но работодатель не написал, удалённая она или офисная.

В таком случае расширение не должно автоматически считать её удалённой.

Проект создавался как личный инструмент для поиска работы и автоматизации просмотра большого количества Telegram-вакансий.

Это не официальный продукт Telegram.

Telegram Job Collector:

- не связан с Telegram;
- не связан с BotFather;
- не гарантирует актуальность вакансий;
- не гарантирует добросовестность работодателей;
- не заменяет самостоятельную проверку вакансии перед откликом.

Расширение работает только с публично доступной информацией Telegram.
