Telegram Job Collector

Без Telegram User API и без ИИ.
Расширение читает публичные Telegram-каналы и поддерживаемые публичные группы, фильтрует сообщения и отправляет подходящие вакансии в твоего BotFather-бота.

1. Telegram-бот

Сначала открой созданного бота в Telegram и нажми Start или отправь ему /start. Затем нажми «Найти Chat ID».

2. Каналы

Для обычных каналов всё работает как раньше. Для публичных групп расширение использует публичные Telegram Post Widgets. Для @edmarketclubjob и @vakansii_infobiz bootstrap уже встроен. Для другой группы можно один раз вставить ссылку на любое её сообщение: https://t.me/group/123456.

3. Фильтры

Аудит без отправки использует тот же фильтр, но ничего не отправляет в Telegram. Он нужен, чтобы проверить, не отбрасываются ли хорошие вакансии.

Вакансии с неуказанным форматом больше не теряются: они лежат отдельно в разделе «Формат работы не указан» и не отправляются в основной поток. В JSON нет Bot Token и Chat ID.
